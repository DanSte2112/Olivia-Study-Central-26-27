2. Las herramientas — Painting tools

Learn how to answer “¿Qué usa un artista para pintar?” (What does an artist use to paint?)

Model sentence: El artista usa un pincel y pinturas para pintar. (The artist uses a paintbrush and paints to paint.)

The teacher listed “herramientas” but did not give specific tool names. These are useful example vocabulary words to practice; confirm the precise list from class notes.

3. Los estilos — Art styles

Be able to distinguish these in Spanish, not just in English.

Memory trick: Realista = se parece a la realidad. Abstracto = formas y colores no realistas. Impresionista = luz, color y pinceladas visibles.
